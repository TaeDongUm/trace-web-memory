# Trace

> 분명 봤는데, 어디서 봤지?

웹에서 봤던 페이지를 의미 기반 Memory로 저장하고, 나중에 불완전한 자연어 기억으로 다시 찾는 서비스입니다.

## 이번 작업에 포함된 것
- Landing
- 로그인 없이 둘러보기 Demo
- Demo 자연어 검색 UI
- 검색 근거 UI
- 관련 기억 UI

## 로컬 실행
```bash
npm install
npm run dev
```

- `/` : Landing
- `/demo` : 로그인 없는 Demo

다음 작업은 `Supabase + Google OAuth + RLS` 연결입니다.

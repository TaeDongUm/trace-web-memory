# Trace

> 분명 봤는데, 어디서 봤지?

웹에서 봤던 페이지를 의미 기반 Memory로 저장하고, 나중에 불완전한 자연어 기억으로 다시 찾는 서비스입니다.

## 체험할 수 있는 기능
- 로그인 없는 데모: 공개 콘텐츠 10개의 예시 기억 검색
- 한국어 단서·동의어·가격·날짜를 이용하는 브라우저 내 규칙 기반 검색
- 일치한 근거와 일치하지 않거나 확인할 수 없는 조건 표시
- 검색 후보 선택, 콘텐츠 유형 필터, 같은 주제의 기억, 개별 원본 링크
- Google 로그인 후 개인 화면에서 저장하고 싶은 페이지 주소를 직접 입력해 저장
- 저장 시 Gemini(무료 티어)가 요약·분류·태그를 자동 생성 (실패하거나 키가 없으면 URL/제목만으로 안전하게 저장)

데모는 외부 AI를 호출하거나 개인 브라우징 기록을 수집하지 않습니다. 저장일은 2026-09-20을 기준으로 만든 가상 기록이며 가격은 데모 스냅샷입니다. 원본 사이트의 현재 정보와 다를 수 있습니다. 검색 가능한 표현에는 한계가 있습니다. 개인 저장·AI 구조화는 Google 로그인 후 제공되며, 현재 페이지를 자동으로 감지해 저장하는 Chrome 확장 프로그램과 개인 기억에 대한 자연어 검색은 아직 제공하지 않습니다(지금은 URL을 직접 입력해 저장). Google 로그인과 개인 기억 조회는 Supabase 설정 후 사용할 수 있습니다.

## 기술 구성
Next.js App Router, React, TypeScript, 일반 CSS를 사용합니다. Supabase(Auth, Postgres, RLS)로 로그인과 개인 데이터를 관리하고, 저장 시 Google AI Studio의 Gemini 무료 API로 요약·태그를 생성합니다. 데모는 API 키 없이 실행됩니다.

## 로컬 실행
```bash
npm install
npm run dev
```

- `/` : Landing
- `/demo` : 로그인 없는 Demo
- `/login`, `/home` : Google 로그인 및 개인 화면

계정 연결: [Supabase 및 Google 설정 안내](docs/SUPABASE_SETUP.md). `.env.example`을 참고하며, 환경변수가 없으면 로그인 준비 안내를 표시합니다. `GEMINI_API_KEY`가 없으면 AI 요약 없이 URL/제목만으로 저장됩니다.

## 검증 명령
```bash
npm test
npm run build
```

검색 단위 테스트는 주요 예시와 가격·날짜 경계, 빈 입력, 결과 없음, 관련 기억 분리 및 URL 형태를 확인합니다. 저장 입력 검증과 AI 응답 정제 로직도 단위 테스트로 확인합니다.

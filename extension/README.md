# Trace 확장 프로그램 (개발자 모드 설치)

현재 페이지를 수동으로 Trace에 저장하는 최소 기능만 제공합니다. 자동으로 방문 기록을 수집하지 않으며, 아이콘을 클릭한 시점의 현재 탭 정보만 읽습니다.

## 설치 방법

1. Chrome 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭
4. 이 저장소의 `extension` 폴더 선택

## 사용 방법

1. [trace-web-memory.vercel.app](https://trace-web-memory.vercel.app)에서 Google로 로그인
2. 저장하고 싶은 공개 페이지(블로그, 유튜브 등)로 이동
3. 툴바의 Trace 아이콘 클릭
4. 저장 결과를 보여주는 새 탭이 열립니다 — 확인 후 닫으면 됩니다

## 동작 방식과 제한

- `https://`로 시작하는 페이지만 저장 대상입니다. `chrome://`, 로컬 파일 등은 차단되고 아이콘에 짧게 "차단" 표시가 뜹니다.
- 페이지 본문을 읽지 않고 제목과 주소만 전송합니다. 비밀번호·결제·로그인 폼 값 등은 수집하지 않습니다.
- 저장은 Trace 웹사이트의 `/save` 페이지가 처리합니다(같은 사이트라 로그인 세션이 그대로 적용됩니다). 로그인 상태가 아니면 로그인 화면으로 이동합니다.
- 저장 시 Gemini가 요약·태그를 자동으로 만들며, 실패해도 주소·제목만으로 안전하게 저장됩니다.
